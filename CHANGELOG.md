# Changelog

## [Unreleased]
### Added
- Next.js 16 + MUI 9 project scaffold with App Router, TypeScript and ESLint
- MUI theme carrying the 晴空 design tokens (palette, typography, 760/1000px breakpoints)
- Shared layout: sticky header with mobile menu, footer with newsletter form (visual only)
- Home page: hero with vertical title, about, works, shop, booking and journal sections
- Shared content data (`src/data`) with placeholder copy for works, products, services and posts
- Works page (`/works`): page header, category filter and gallery grid, custom-order call to action
- Shop page (`/shop`): category filter, product grid and shopping notice
- Product detail page (`/shop/[id]`) with gallery, specs, quantity stepper and add-to-bag button (visual only)
- Booking page (`/booking`): service details with anchors, booking form (visual only) and FAQ accordion
- Journal page (`/journal`): featured post, tag filter and post list
- Post page (`/journal/[slug]`) with article layout and newer/older navigation
- README with setup, structure and content-editing guide
